# The Philips BDP 3280 Hacking Project
A repository containing info about the Philips BDP 3280,how to exploit it and get access to a root shell.

The final objective is to create a custom linux environment that has  access to the display(hdmi & composite), the usb ports, and possibly the LCD. No support for bluray as i broke mine...

This repo is organized onto files, heres the list:

  - [Tutorials (How to get UART, shell...)](/docs/tutos.md)
